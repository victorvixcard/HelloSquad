# docs/parciais/

Relatórios de progresso e fechamento de cada fatia, escritos pelos agentes executores e commitados junto com o código.

- `<fatia>-progresso.md` — atualizado durante o trabalho (o que foi feito, o que está em andamento, o próximo passo). Permite retomar do disco se a sessão morrer.
- `<fatia>-relatorio.md` — escrito ao fechar: o que foi entregue, comando de verificação e sua saída, pendências, perguntas para o dono.

Nomenclatura: letra do agente + número da fase + sufixo opcional. Ex.: `J0`, `S0`, `A0`, `H0`, `S1a`.
