## 3. Decisões técnicas (não mudam o combinado)

1. **Unidade + seções.** O §3 do `SUPER_ADMIN.md` põe "SOUL por seção, skills, ferramentas" em `agent_prompt_sections`; separei em cabeçalho (`squad_versions`, que guarda skill, `agent.yaml` e regras compartilhadas como texto bruto, para o export sair byte a byte, com os comentários) e seções (`agent_prompt_sections`, só da SOUL). A **versão é da Alma inteira**, como no SA0 ("Versão N da Alma pronta para publicar"); cada seção diz em que versão mudou por último.
2. **Mesmo hash por origem.** O banco monta os mesmos bytes dos arquivos; o hash do prompt (manifesto da S1c) é o mesmo, então os hashes do SA0 e os testes da S1c continuam valendo. Seção fora do prompt fica no arquivo com `<!-- fora do prompt -->` (muda o hash; some do system).
3. **O banco vale.** `make squad-seed` só cria o que falta; arquivo divergente é listado, nunca sobrescreve o painel. Levar mudança de arquivo para o banco é explícito (`hellosquad-squad seed --import-changes`, versão nova auditada como sistema).
4. **`agent_prompt_versions`** continua uma linha por hash; quando o mesmo hash já existia vindo dos arquivos, a primeira gravação a partir do banco preenche `origin`/`sources` uma vez (sem mudar hash nem arquivos).
5. **Catálogo de ferramentas** = união das listas dos sete `agent.yaml` (como o SA0); fora dele, 422. `modelo.padrao`/`triagem` só com modelo da tabela de preços (`LLM_PRICES`), para nenhum run ficar sem custo.
6. **Tokens estimados** = caracteres/4, marcado como estimativa (a contagem real vem do `usage` de cada run). Contexto de exemplo: marca fictícia "Miolo", pt-BR, pedido de exemplo.
7. **Regras de negócio** seguem o modelo da SA1 (cada gravação é versão nova; a mais recente vale) e a flag "entra no prompt" é do **documento**, como no SA0 e no schema da SA1; o portão do runtime é publicar o rascunho das regras compartilhadas.
8. **Limpeza dos testes:** pytest e roteiro apagam as versões que criaram com os gatilhos desligados só nessa limpeza (`session_replication_role = replica`), para o banco local voltar à versão 1 de tudo. No produto, nada se apaga.
